# Noël chez Meiji

Démo non officielle de Meiji Sushi & Grill. L’accueil et les bannières du menu associent branches de sapin, guirlandes et neige animée. Le bouton Pause neige mémorise le choix sur cet appareil.

Les sources et les licences des médias et des polices se trouvent dans le dossier assets. Les avis sont désactivés.
